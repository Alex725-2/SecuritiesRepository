# Предметная модель

## Справочники и исторические данные

| Сущность | Значение и ключ |
|---|---|
| ManagementCompany | УК управляет фондами; уникальный INN |
| Fund | Отдельный имущественный комплекс; уникальный Code, ссылка на УК |
| Security | Бумага; уникальный ISIN, валюта, тип и признак активности |
| Custodian | Депозитарий хранения; уникальный Code |
| CustodyAccount | Счёт одного фонда в депозитарии; уникальная пара Custodian/AccountNumber |
| Exchange | Биржа; отдельный справочник торговых площадок |
| Position | Остаток по составному ключу Account/Security; Quantity и Version |
| Operation | Учётное движение, ключ идемпотентности, реквизиты и ссылка корректировки |
| LedgerEntry | Неизменяемое знаковое изменение остатка |
| SecurityPrice | Котировка по Security/PriceDate, с валютой и источником |
| FundValuation | Оценка по Fund/ValuationDate, активы, обязательства, СЧА |
| FundUnits | Количество паёв по Fund/EffectiveDate |
| ReconciliationRun | Снимок сверки фонда и момент запуска |
| ReconciliationItem | Контрольный Expected и внутренний Actual по счёту и бумаге |
| OutboxMessage / InboxMessage | Доставка события и однократная фиксация обработки |

**УК** принимает решения по управлению. **Фонд** — объект учёта активов. **Брокер** исполняет поручения на сделки, в этом MVP отдельной сущности брокера нет. **Биржа** организует торги. **Депозитарий** учитывает права и хранение, а специализированный депозитарий также выполняет контрольные функции. Наличие справочника Exchange не означает реализации торгового учёта. Счёт хранения не является биржевым стаканом или расчётным банковским счётом.

## Правила

Количество — `decimal` / `numeric(28,8)`. Количество команды строго положительно, максимум восемь десятичных знаков; остаток неотрицателен. Фонд и счета должны быть Active, бумага — IsActive. Внутренние переводы разрешены только внутри одного фонда, между разными счетами. До создания новой позиции блокируется родительский счёт: отсутствие строки Position не создаёт гонку.

Credit 100: одна проводка +100, источник и документ обязательны. Debit 30: одна проводка −30, назначение и документ обязательны. Односторонние внешние движения не называются полноценной двойной записью.

Transfer 80 из A в B: проводки (A, −80), (B, +80), сумма равна нулю. При A=100 два конкурентных перевода по 80 не могут оба завершиться. Блокировка счёта удерживается до фиксации всех записей транзакции.

Reverse создаёт новую операцию с `ReversesOperationId` и инверсией всех исходных проводок. Исходный журнал остаётся прежним. Уникальный индекс запрещает две корректировки одного оригинала. Корректировка корректировки в MVP запрещена. Нехватка остатка для обратного движения приводит к rollback.

Успешная команда с тем же глобальным IdempotencyKey и теми же параметрами возвращает сохранённый результат. Ключ с другими параметрами — конфликт. Неуспешные транзакции не резервируют ключ и не создают операцию. Время — UTC. ExternalId хранится как необязательный реквизит, а не заменяет ключ идемпотентности.

## Сверка

Оператор передаёт полный набор контрольных остатков фонда. Ожидаемые и внутренние пары объединяются, отсутствующая сторона равна нулю. Чужие счета, неизвестные бумаги, дубликаты и отрицательные значения запрещены. REPEATABLE READ даёт согласованный снимок. Результат сохраняется, позиции не исправляются автоматически.

## Оценка

Позиция на конец даты UTC = сумма проводок до начала следующей даты. Применяется котировка строго на запрошенную дату. Последняя запись FundUnits с EffectiveDate ≤ дате определяет количество паёв. Оценка не прогнозирует будущие позиции. Корректировки отражаются датой их фактического проведения.

Активы = сумма Quantity × Price. СЧА = активы − обязательства. Стоимость пая = СЧА / UnitsOutstanding. Все компоненты должны иметь одну валюту, FX в MVP отсутствует. Без цены или положительного количества паёв расчёт отклоняется. Активы и стоимость пая округляются до 8 знаков, MidpointRounding.ToEven. Хранение и версия оценки независимы от справочника фонда. Это демонстрационная методика, не официальная нормативная СЧА.
