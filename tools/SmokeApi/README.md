# HTTP-проверки без инфраструктуры

`smoke_api.py` ожидает API в Development на 127.0.0.1:5088, без доступной PostgreSQL. Проверяет Swagger, авторизацию, роль Auditor и health 503. `smoke_production.py` ожидает API в Production на 127.0.0.1:5089 и проверяет отсутствие тестового issuer и Swagger.

Оба сценария используют только стандартную библиотеку Python и не изменяют учёт. Адреса фиксированы специально для изолированного локального прогона. Запускайте API с JWT-ключом из окружения. Для форматирования C# можно выполнить `dotnet run --project tools/FormatSource` из корня; Roslyn берётся из установленного SDK.

`decimal_contract.py` также требует Development API на 5088 с **заведомо недоступной** PostgreSQL. Проверяет 400 для JSON-number quantity, 503 для корректной decimal-строки при недоступной БД и string-схему decimal в Swagger. Не запускайте его против работающей пользовательской БД: сценарий отправляет команду и предполагает отказ соединения.
